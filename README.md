# BioRipple

Research dependency intelligence demo. Static site, no build step. All data is fictional and illustrative.

## Publish on GitHub Pages
1. Create a new repository on GitHub.
2. Upload the files from this folder (index.html, style.css, script.js, .nojekyll, README.md) to the repository root.
3. Open Settings > Pages, choose "Deploy from a branch", select `main` and `/ (root)`, then Save.
4. Your site appears at `https://<your-username>.github.io/<repo-name>/` after a minute or two.

Fonts load from Google Fonts. To run locally, open index.html in a browser.
